# 엄현호 · 프론트엔드 포트폴리오

사용자의 관점에서 문제를 풀고, 팀과 함께 목표에 도달합니다.

Nexon Open API를 활용한 메이플스토리M 검색 서비스 ‘메엠지지’를 직접 개발하고 운영하고 있습니다. 출시 이후에도 사용자 피드백과 실제 이용 흐름을 바탕으로 UI/UX를 개선하고, 성능 최적화와 구조 개선을 꾸준히 이어가고 있습니다.

정제되지 않은 데이터를 사용자가 한눈에 이해할 수 있는 화면으로 만드는 과정에 관심이 많습니다. 자주 찾는 정보를 먼저 보여주고, 검색 기록·스크롤·포커스 같은 작은 인터랙션까지 사용 흐름에 맞게 설계하며 더 나은 경험을 고민합니다.

혼자 문제를 해결하는 것뿐만 아니라 팀원들과 목표를 맞추고 함께 결과를 만들어가는 과정에서도 큰 성취감을 느낍니다. 팀장으로 프로젝트를 이끌며 데일리 스크럼과 스프린트 회고를 통해 진행 상황과 의견을 꾸준히 공유하며 협업해 왔습니다.
